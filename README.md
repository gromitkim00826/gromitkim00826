### 안녕하세요, 김유나입니다 👋

임베디드 Linux 커널 드라이버와 Qt 기반 임베디드 UI를 다룹니다.
VEDA 4기 임베디드 시스템 과정을 수료했고, 하드웨어부터 애플리케이션까지 전체 스택을 이해하는 개발자를 지향합니다.
